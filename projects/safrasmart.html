ILLUSTRATIVE MOBILE INTERFACE

The problem

Agricultural producers and buyers need a clear way to discover products, distinguish direct sales from auctions and follow negotiations in one mobile experience.

My contribution

I am developing the Flutter application and its Firebase integrations, including product discovery, listing management, accounts, favorites and communication workflows. The source is organized into screens, view models, service classes and reusable widgets.

Engineering decisions

Provider and ChangeNotifier connect application state to the interface. TypeScript Cloud Functions handle server integrations and usage controls. Weather and sandbox shipping requests go through authenticated backend functions, while Firestore and Storage rules define ownership and access boundaries.

Testing the boundaries.

The October 2026 security review added regression tests for input validation, private profile access, document ownership, chat participants and media uploads.

Verification snapshot
16 backend tests and 11 Firestore/Storage emulator tests passed in the review environment. The TypeScript backend compiled successfully.

These checks cover defined scenarios. Flutter analysis, device builds and live provider integrations still require validation. Passing tests do not imply complete security or production readiness.

Current status

The project is in development. Financial operations and sensitive client-side mutations are temporarily blocked while trusted server workflows are completed. Android/iOS device validation, infrastructure configuration and staging checks remain pending; this is not a launched commercial marketplace.
