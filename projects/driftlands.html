Making a world that stays coherent.

What started as a university game project grew into a systems-focused playable prototype. The world is made of seeded islands, connected by bridges and presented through a streaming isometric view.

The core engineering challenge was keeping the world state consistent while the player explored, collected materials, built structures, fought creatures and saved progress.

Design principle: world data remains authoritative. Navigation logic uses terrain and occupancy state, not rendered Tilemaps or GameObjects.

Built to interact.

  • Procedural islandsSeeded Perlin-based world generation, multiple biomes and chunk-based streaming.
  • Pathfinding & navigationA* routing across the world with terrain weights and recalculation when paths change.
  • Inventory & craftingItem stacks, resource gathering, recipes, storage and workstations.
  • Combat & creaturesActor states, enemy interactions, damage, recovery and resource harvesting.
  • Reliable savesVersioned JSON persistence, autosave, backup restoration and corrupt-save handling.
  • World atmosphereLighting, weather, audio, day/night cycle and player feedback.

Test the logic. Not just the scene.

The code is organized into domain, infrastructure and presentation layers. I kept pure C# game rules independent of Unity so they can be evaluated without needing to load a scene.

Domain → grid, game state and rules
Infrastructure → generation and persistence
Presentation → input, Tilemaps, rendering and HUD
Tests → standalone .NET runner + Unity EditMode checks

That separation lets the game replan navigation when world occupancy changes and helps keep saves predictable as new gameplay systems are added.

// Route search restarts when the world changes.
if (revision != world.Revision)
{
    frontier.Clear();
    cost.Clear();
    parent.Clear();
    closed.Clear();
    visited = 0;
    revision = world.Revision;
    cost[start] = 0;
    frontier.Push(start, start.Distance(destination) * LandCost);
}

// Traverse valid neighbors with weighted terrain cost.
foreach (var direction in Cell.Directions)
{
    Cell next = current + direction;
    if (!ProtectedChunks.Contains(ChunkData.At(next))
        || closed.Contains(next)
        || !world.CanStep(current, next)) continue;

    int g = cost[current] +
        (world.Tile(next).IsWater ? SwimCost : LandCost);
    if (cost.TryGetValue(next, out int previous)
        && previous <= g) continue;

    cost[next] = g;
    parent[next] = current;
    frontier.Push(next, g + next.Distance(destination) * LandCost);
}
