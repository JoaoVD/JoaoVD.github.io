SIGMA Dashboard.

A clearer view of everyday work.

An automatically refreshed maintenance dashboard, designed for a shared TV.

View on GitHub ↗Read the documentation ↗

Explore the public portfolio edition with fictitious demo data and generic branding.

The problem

Maintenance staff needed a shared view of open work orders on a 43-inch Full HD display.

My contribution

I developed a dashboard that retrieves open work orders, paginates the display and refreshes data every minute. The interface prioritizes legibility at a distance, with equipment, description and status.

Engineering decisions

The dashboard preserves the last successful snapshot during connection failures and shows a visible connection indicator. A complete fresh response replaces the snapshot after reconnection.

Current status

The dashboard is in operational use. A separate public portfolio edition is available on GitHub, with fictitious demo data, generic branding and automated regression tests. Production credentials and company records remain private.
